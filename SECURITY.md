## Schwachstellen melden

Sollten Sie eine Sicherheitslücke oder ein fehlerhaftes Verhalten in diesem Audit-Tool feststellen, eröffnen Sie bitte kein öffentliches Issue mit sensiblen Daten.

Erstellen Sie stattdessen einen privaten Sicherheitsbericht über die GitHub Security Advisory Funktion dieses Repositories oder kontaktieren Sie den Maintainer direkt.
